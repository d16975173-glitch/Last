# Последнее слово: Telegram Mini App

Что внутри:
- `public/index.html`: сама игра (одна страница, вся графика и анимации внутри);
- `server.js`: сервер: отдаёт игру, проверяет вход через Telegram, хранит профили, держит онлайн-комнаты (WebSocket);
- `bot.js`: бот: команда /start и кнопка «Играть»;
- `package.json`, `.env.example`: зависимости и пример настроек.

## Запуск за 6 шагов (Render, бесплатно)

1. **Создай бота.** В Telegram открой @BotFather, отправь `/newbot`, задай имя и username. Сохрани **токен**.
2. **Залей проект на GitHub.** Создай репозиторий на github.com, нажми *Add file → Upload files* и загрузи всё содержимое этой папки (вместе с папкой `public`). Это можно сделать и с телефона.
3. **Создай сервис на Render.** На render.com: *New → Web Service* и выбери свой репозиторий.
   - Build Command: `npm install`
   - Start Command: `npm start`
4. **Добавь переменные окружения** (Environment):
   - `BOT_TOKEN`: токен из шага 1
   - `JWT_SECRET`: любая длинная случайная строка
   - `WEBAPP_URL`: адрес сервиса (после первого деплоя Render покажет его, например `https://last-word.onrender.com`). Вставь и нажми *Manual Deploy → Deploy latest commit*.
5. **Открой бота** в Telegram, отправь `/start` и нажми «▶ Играть». Кнопка «Играть» появится и в меню бота.
6. **(По желанию)** В @BotFather: `/newapp` даёт красивую ссылку вида `t.me/твой_бот/game`.

## Запуск на своём компьютере
```
npm install
cp .env.example .env     # заполни значения
npm run dev
```
Telegram требует HTTPS, поэтому для теста пробрось порт через `cloudflared tunnel --url http://localhost:3000` или `ngrok http 3000` и подставь выданный адрес в `WEBAPP_URL`.

## Как работает вход
- В Telegram игра сама отправляет `initData` на `/api/login`. Сервер проверяет подпись токеном бота и выдаёт сессию. Пароль не нужен.
- Профиль (монеты, покупки, задания, рекорды) сохраняется на сервере и подгружается при следующем входе.
- Вне Telegram (в обычном браузере) работают локальные аккаунты с паролем и кодом восстановления.

## Онлайн-комнаты
Игрок создаёт комнату, получает 4-значный код, друзья входят по коду. Прогресс всех игроков синхронизируется через `/ws`. Комнаты живут в памяти сервера, до 10 игроков в комнате.

## Важно знать
- **Данные в `data.json` на бесплатном Render стираются** при перезапуске и новом деплое. Для постоянного хранения подключи Render Disk или базу (Postgres, Supabase). Нужно заменить только блок «хранилище профилей» в `server.js`.
- **Монеты считает клиент**, поэтому хитрый игрок может их подделать. Для серьёзной игры перенеси подсчёт наград и покупки на сервер (`/api/buy`, `/api/result`).
- **Вход через Google** не подключён: нужен Client ID (`GCID` в `index.html`) и обработчик `/api/google` на сервере, который проверяет токен через `google-auth-library`. Внутри Telegram Google часто блокирует вход, так что надёжнее делать привязку через внешний браузер.
- Бесплатный Render «засыпает» без запросов, первый запуск может занять около минуты.
- Бот работает в личных чатах: кнопки Web App в группах Telegram не поддерживает.
